PROGRESS LEDGER - ANDROID INSTALLABLE WEB APP

This package turns the existing Progress Ledger into an installable PWA.

To install on Android:
1. Upload all files in this folder to a static HTTPS host (for example GitHub Pages or Netlify).
2. Open the hosted URL in Chrome on your Android phone.
3. Open Chrome's menu and choose "Install app" or "Add to Home screen".
4. Launch Progress Ledger from the new home-screen icon.

The app shell is cached for offline use after the first successful visit.
Your entries are stored locally in the browser/app origin. Export JSON backups regularly.
Do not rename or separate the files; index.html, manifest.webmanifest, sw.js and the icons
must remain together in the same folder.

This is a PWA, not a signed native APK. It installs through Chrome and does not require
Play Store publication.
